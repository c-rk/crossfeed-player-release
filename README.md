# crossfeed player

A music player for Android that keeps a private listening diary, plays the songs on your phone, follows along with the words, and turns a link from any streaming service into the same song on the one you use. Download [crossfeed-player-0.3.2.apk](crossfeed-player-0.3.2.apk), check it against `SHA256SUMS.txt` if you like, and install it. Android will ask you to allow installs from your browser or file manager the first time. Nothing you play leaves the phone.
